# Калькулятор баллов ПГАС — Общественная деятельность

**Южно-Российский государственный политехнический университет (НПИ) имени М.И. Платова**

## 📋 Описание

Веб-приложение для предварительного расчёта баллов повышенной государственной академической стипендии (ПГАС) по направлению **«Общественная деятельность»**.

Калькулятор разработан строго на основе **Положения о ПГАС ЮРГПУ (НПИ)**, раздел 4.3.

## ⚠️ Важно

> Все баллы являются **предварительными** и используются **только для ознакомления**.  
> Данный калькулятор **не является официальным инструментом** расчёта стипендии.  
> Окончательное решение о назначении ПГАС принимает конкурсная комиссия университета.
